# تصميم التفاعل بين الإنسان والذكاء الاصطناعي وتجربة المستخدم

Human-AI Interaction and Experience Design

مسار التنفيذيين والقادة · أكاديمية سدايا · LDS-PRD-203 · المستوى 200

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

يصمم المشاركون طريقة عمل الناس مع مساعد ثنائي اللغة ووكيل لحجز المواعيد لدى جهة افتراضية لخدمات المرافق. فيدققون أنماط التفاعل، ويضبطون التوقعات وفق القدرات المقيسة، ويعرضون المصادر وعدم اليقين، ويضيفون التأكيد والتراجع لإجراءات الوكيل، ويصممون الإحالة إلى موظف بشري، ويتحققون من إمكانية الوصول ومن النص العربي المكتوب من اليمين إلى اليسار، وينتهون بنموذج أولي يختبرونه مع المستخدمين. أما بناء الواجهة الأمامية فيغطيه المقرر DEV-SWE-203.

**الصيغة:** دورة مكثفة: 3 أيام تدريبية ويوم للمشروع الختامي، مع عمل تحضيري موجه ومهمة متابعة متعقَّبة

**صفحة المقرر:** https://sdaiaacademy.github.io/lds-prd-203/

## نواتج التعلم

| | نواتج التعلم | المستوى | الدليل |
|---|---|---|---|
| LO1 | يصف أنماط التفاعل مع المساعدات والوكلاء وخطر الثقة الذي يحمله كل نمط، استنادًا إلى ستة منتجات تستخدم المحادثة والاقتراح المضمّن والصياغة ثم المراجعة والمهام المنفذة بعد الموافقة والمهام في الخلفية | Awareness | جدول أنماط مشروح فيه خطر وإجراء للحد منه لكل منتج |
| LO2 | يصوغ مواد التعريف الأولي وطريقة عرض المصادر وإشارات عدم اليقين بما يطابق القدرات المقيسة، استنادًا إلى نتائج تقييم تبين مواضع إخفاق المساعد | Applied | شاشات مشروحة تربط كل إشارة بدليلها |
| LO3 | يعدّ مسارات للتعافي والتصعيد فيها تأكيد وتراجع متدرجان بحسب قابلية كل إجراء من إجراءات الوكيل للتراجع عنه، استنادًا إلى ستة إجراءات للوكيل وقواعد الإحالة في الخدمة | Applied | مسارات تغطي كل إجراء وكل إخفاق وكل رفض |
| LO4 | يختبر النموذج الأولي وفق معايير إرشادات إتاحة محتوى الويب (WCAG) باستخدام قارئ شاشة ولوحة المفاتيح وحدها، على نموذج أولي يعرض الاستجابات بالبث المتدفق | Applied | تقرير إمكانية وصول يبين المشكلات والمعايير والإصلاحات |
| LO5 | يختبر التخطيطات العربية ومختلطة الاتجاه مع الأرقام والتواريخ والأسماء اللاتينية والمدخلات المتناوبة لغويًا، باستخدام عشرين سيناريو اختبار ثنائي اللغة | Applied | سجل لعيوب النص ثنائي الاتجاه مع الإصلاحات |
| LO6 | يقيّم التصميم في اختبار قابلية استخدام يديره ميسِّر ويقيس نجاح المهام والاعتماد المفرط عند أخطاء مزروعة عمدًا وزمن التعافي، باستخدام خمسة مشاركين في الاختبار وأربع مهام | Performance | تقرير اختبار فيه ثلاثة تعديلات على التصميم، يُناقَش في جلسة نقد |

## المشروع الختامي

نموذج أولي مختبَر مع مسوغات التصميم وتقرير قابلية الاستخدام، يُناقَش في جلسة نقد يختار فيها المراجعون حالة إخفاق ويستعرض المشارك مسار التعافي منها

**التسليم:** REPLACE: ما يسلّمه المشاركون وكيف: رابط مستودع عام، أو مجلد مشترك لمقرر بلا برمجة

## المتطلبات السابقة

- يملك خبرة سابقة في تصميم واجهة رقمية أو خدمة رقمية أو إعداد مواصفاتها أو اختبار قابلية استخدامها
- يملك خبرة في استخدام مساعد ذكاء اصطناعي ووكيل ينفذ إجراءات نيابة عن المستخدم

## الأدوات

كل سطر قدرة، والأمثلة قابلة للتبديل.

- **بناء النماذج الأولية التفاعلية:** Penpot, أي أداة تصميم تدعم النماذج الأولية التفاعلية, نموذج أولي بلغة HTML
- **فحص إمكانية الوصول:** axe-core, WAVE
- **قارئات الشاشة:** NVDA, VoiceOver, TalkBack
- **نموذج لغوي لتوليد استجابات واقعية:** نموذج مستضاف مفتوح الأوزان, أي واجهة برمجة تطبيقات (API) تجارية
